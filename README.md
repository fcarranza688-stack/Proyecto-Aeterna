Aeterna: Pantheon
Un RPG táctico por turnos desarrollado en Python.
Aeterna: Pantheon es un videojuego de combate por turnos donde la estrategia y la gestión de habilidades son la clave para la victoria. Enfrenta a poderosos enemigos en un entorno diseñado con estética Pixel Art, impulsado por una lógica de combate robusta y algoritmos recursivos.

Características Principales
Sistema de Combate por Turnos: Mecánicas clásicas de RPG con gestión de puntos de vida, energía y estados.
Interfaz Gráfica : Desarrollado íntegramente con la librería Tkinter, optimizando la experiencia de usuario sin dependencias pesadas.
Motor Lógico: Implementación de recursividad para procesos críticos del juego (como la gestión de eventos o menús anidados).
Estética Retro: Uso de assets en Pixel Art para una experiencia visual nostálgica y limpia.

Tecnologías Utilizadas
Lenguaje: Python 3.14.3
Interfaz: Tkinter
Lógica: Algoritmos de recursividad aplicada.
Control de Versiones: Git / GitHub
